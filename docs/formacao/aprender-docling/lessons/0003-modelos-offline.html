Aprender Docling · Lição 03

Modelos offline

Fazer o Docling correr numa máquina do CRL, que não tem internet.

Porque é que isto interessa

Foi a restrição que puseste em cima da mesa, e é a que mata projetos. Um extractor que só funciona na máquina de quem o escreveu não entra em produção. O docs/institucional/requisitos-tecnicos.md do AppCCT já documenta instalação sem internet — para o Docling essa exigência tem duas metades: o pacote e os modelos. As duas resolvem-se de maneiras diferentes.

1. As duas metades

MetadeDe onde vemComo se resolve offline
O código Python (docling + PyTorch + …)PyPI, no pip installpip download numa máquina com rede, cópia dos wheels, pip install --no-index
Os pesos dos modelos (layout, TableFormer, …)Hugging Face, na primeira conversãodocling-tools models download e depois artifacts_path

A segunda metade é a que apanha toda a gente. A instalação corre bem, os testes correm bem na máquina de desenvolvimento, e a primeira conversão na máquina do CRL falha com um erro de rede — porque só nesse momento é que o Docling vai buscar os pesos.

2. Na máquina com rede: puxar os modelos

.venv-docling/bin/docling-tools models download --output-dir ./modelos-docling

Sem --output-dir, os modelos caem em ~/.cache/docling/models — o que serve para ti, mas não serve para copiar. Com --output-dir ficas com uma pasta que podes levar numa pen.

Por omissão vêm os modelos do pipeline standard: layout, TableFormer, classificador de imagens, fórmulas/código, e os do RapidOCR. Se não vais usar OCR nas convenções do BTE, esses últimos são peso morto — mas é peso que não estorva. Há um --all que traz tudo, incluindo os modelos VLM: não uses, são gigabytes que a tua missão não precisa.

Para escolher exactamente, existe a via programática, com um interruptor por modelo:

from pathlib import Path
from docling.utils.model_downloader import download_models

download_models(
    output_dir=Path("./modelos-docling"),
    with_layout=True,        # indispensável: é ele que reconhece as cláusulas
    with_tableformer=True,   # indispensável: tabelas salariais
    with_code_formula=False,
    with_picture_classifier=False,
    with_rapidocr=False,     # PDFs do BTE são digitais, não precisam de OCR
    progress=True,
)

3. Na máquina do CRL: apontar para eles

Três maneiras, a mesma coisa. Escolhe uma e sê consistente:

# 1. na linha de comandos
docling convencao.pdf --artifacts-path ./modelos-docling --no-ocr --to json

# 2. em Python
opcoes = PdfPipelineOptions(artifacts_path=Path("./modelos-docling"), do_ocr=False)

# 3. por variável de ambiente — a melhor para um lançador .bat/.command
export DOCLING_ARTIFACTS_PATH=/opt/modelos-docling
Testa como o CRL, não como tu

Não confies em ter configurado bem: prova-o. Desliga a rede da máquina de desenvolvimento, apaga ~/.cache/docling e ~/.cache/huggingface, e corre a conversão. Se passar, passa no CRL. Se falhar, falha aqui — que é onde custa barato.

Enquanto escrevia estas lições aconteceu-me exactamente isto ao contrário: o huggingface.co está bloqueado por política de rede no ambiente onde trabalhei, e a conversão morreu com httpx.ProxyError: 403 Forbidden antes de processar um único bloco. É esse o aspecto da falha que te espera no CRL se saltares esta lição.

4. E o pacote?

# máquina com rede — mesma versão de Python e mesmo sistema operativo do destino
pip download docling -d ./wheels-docling

# máquina do CRL
pip install --no-index --find-links ./wheels-docling docling

Conta com vários gigabytes de wheels, quase tudo PyTorch. Se a decisão final for integrar o Docling no AppCCT, isto muda a natureza da instalação da aplicação — hoje são quatro dependências e uns 30 MB. Não é um pormenor de empacotamento: é um argumento a pesar na decisão técnica, e pertence à nota que vais escrever no fim.

6. O teu ganho

Guarda isto

Sabes separar as duas metades — pacote e pesos — e sabes provar que a configuração offline está boa, em vez de esperar para descobrir no CRL. Escreve o resultado no relatório do tracer: quantos GB de wheels, quantos MB de modelos, quanto tempo por página em CPU. Esses três números são metade da decisão técnica.
