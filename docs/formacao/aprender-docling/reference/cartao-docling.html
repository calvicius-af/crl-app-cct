Cartão de referência

Docling 2.121.0 · docling-core 2.92.0 · para PDFs de convenções coletivas do BTE. Imprime bem.

Confiança

As opções, valores por omissão e flags abaixo foram lidos do pacote instalado, não da documentação publicada. Sempre que uma versão nova entrar, reconfirma com docling convert --help — a documentação publicada atrasa-se.

Linha de comandos

docling FICHEIRO.pdf --to md --to json --output ./saida/

--no-ocr                    # PDFs do BTE são digitais → usa sempre
--page-range 1-4            # experimentar sem esperar
--table-mode fast|accurate  # omissão: accurate
--no-tables                 # mais rápido, perde as tabelas salariais
--pdf-backend docling_parse_v4|pypdfium2
--artifacts-path ./modelos  # obrigatório sem internet
--device cpu|cuda|mps|auto
--num-threads 4
--document-timeout 600
--pdf-password SEGREDO
--debug-visualize-layout    # ver o que o modelo de layout decidiu
-v / -vv                    # verbosidade

--force-ocr está deprecated nesta versão, apesar de a documentação e a skill do próprio pacote ainda a mencionarem. O substituto é --ocr-mode full_page.

Python — o esqueleto

from docling.datamodel.base_models import ConversionStatus, InputFormat
from docling.datamodel.pipeline_options import PdfPipelineOptions, TableFormerMode
from docling.document_converter import DocumentConverter, PdfFormatOption

opcoes = PdfPipelineOptions(do_ocr=False, do_table_structure=True)
opcoes.table_structure_options.mode = TableFormerMode.ACCURATE

conversor = DocumentConverter(
    format_options={InputFormat.PDF: PdfFormatOption(pipeline_options=opcoes)}
)
resultado = conversor.convert("convencao.pdf")   # caminho, URL ou DocumentStream
doc = resultado.document

Duas camadas, sempre: PdfFormatOption por fora, PdfPipelineOptions por dentro. Chave do dicionário é membro do enum InputFormat, nunca a string "pdf".

Lotes e falhas

for r in conversor.convert_all(caminhos, raises_on_error=False):
    if r.status is ConversionStatus.SUCCESS:      ...
    elif r.status is ConversionStatus.PARTIAL_SUCCESS: print(r.errors)
    else:                                          print(r.errors)

Estados: pending, started, success, partial_success, failure, skipped. Num corpus de 289 convenções, raises_on_error=False não é opcional.

Offline

docling-tools models download --output-dir ./modelos-docling
docling FICHEIRO.pdf --artifacts-path ./modelos-docling
export DOCLING_ARTIFACTS_PATH=/opt/modelos-docling

Sem --output-dir, a cache fica em ~/.cache/docling/models. Prova a configuração com a rede desligada e as caches apagadas.
