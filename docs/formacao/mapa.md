# Processo de Formação Pragmática — Mapa de artefactos

## Função

Este mapa evita que o projeto se transforme numa massa de notas soltas. Cada artefacto tem uma função, uma pergunta que responde e um estado.

## Artefactos do processo

| Artefacto | Pergunta que responde | Estado |
|---|---|---|
| Base operacional | Como o processo funciona na v1? | iniciado |
| Análise de necessidades | Porque é que esta aprendizagem é necessária agora? | iniciado |
| Referencial de competências | Que desempenho observável define sucesso? | iniciado |
| Plano de aprendizagem | Que sequência leva da lacuna à competência? | iniciado |
| Plano de exercícios | Que tarefas produzem prática, produção e feedback? | iniciado |
| Rubrica de avaliação | Como se avalia a evidência de competência? | iniciado |
| Registo de capitalização | Que conhecimento entra no vault depois da formação? | por criar |

## Artefactos da primeira instância

| Artefacto | Caso Python+CCT | Critério de utilidade |
|---|---|---|
| Objetivo 3 Cs | Aprender Python no tracer de extração PDF | observável, contextualizado e mensurável |
| Inventário de lacunas | Python, PyMuPDF/Docling, LangExtract, Ollama | lacunas priorizadas por dependência |
| Contexto técnico | fontes autorizadas + notas atomizadas | suficiente para um expert técnico |
| Exercício 1 | extrair texto de um PDF de convenção coletiva | output verificável contra critério |
| Evidência | script, resultado e explicação breve | permite feedback e melhoria |
