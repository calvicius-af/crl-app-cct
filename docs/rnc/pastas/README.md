# Os README de pasta

Um por pasta principal da árvore do RNC. Cada um tem as mesmas cinco secções e nada mais.

1. **O que vive aqui**, numa frase.
2. **O que não vive aqui**, e para onde vai, com o caminho.
3. **Como se chamam os ficheiros**, com o padrão desta pasta e um exemplo real.
4. **Quem escreve e quem lê**, por papéis e não por nomes.
5. **Quando sai daqui**, com a condição que faz um ficheiro passar à fase seguinte ou ir para `9_arquivo/`.

Máximo de uma página. Se passar disso, o que falta é simplificar a pasta.

Copiam-se para dentro da respetiva pasta da árvore de dados, com o nome `README.md`. A fonte fica aqui, versionada com o resto do projeto.

A convenção completa está no [README de gestão documental](../README.md). Em caso de divergência, prevalece esse documento.
