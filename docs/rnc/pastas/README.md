# Os README de pasta

Um por pasta principal da árvore do RNC. Cada um tem as mesmas cinco secções e
nada mais:

1. **O que vive aqui** — uma frase.
2. **O que não vive aqui** — e para onde vai, com o caminho.
3. **Como se chamam os ficheiros** — o padrão desta pasta, com um exemplo real.
4. **Quem escreve e quem lê** — papéis, não nomes.
5. **Quando sai daqui** — a condição exata que faz um ficheiro passar à fase
   seguinte, ou ir para `9_arquivo/`.

Máximo uma página. Se passar disso, o que falta é simplificar a pasta, não
escrever mais.

Copiam-se para dentro da respetiva pasta da árvore de dados, com o nome
`README.md`. A fonte fica aqui, versionada com o resto.
