# `5_redacao/` — os capítulos em elaboração

## O que vive aqui
Um ficheiro por capítulo do relatório, enquanto está a ser escrito e revisto.

## O que não vive aqui
O relatório montado → `6_relatorio/`. O material de que o capítulo parte →
`4_temas/{TEMA}/`. As versões anteriores de um capítulo → `9_arquivo/`.

## Como se chamam os ficheiros
`{codigo_roteiro}_{titulo_curto}.docx`, com o código do roteiro tal como consta
do `temas.csv`:

```text
4_07_remuneracoes.docx
4_08_protecao_dados.docx
```

**A versão ativa não leva data.** É assim que se reconhece que é a atual. Quando
é substituída, a anterior vai para `9_arquivo/5_redacao/` com data:
`4_07_remuneracoes_20270312.docx`.

## Quem escreve e quem lê
Escreve a perita responsável pelo tema — a que consta da coluna
`perita_responsavel` do `temas.csv`. Lê a coordenação, para rever e montar.

## Quando sai daqui
Quando o capítulo é dado por fechado e entra na montagem do relatório. Sai uma
cópia para `6_relatorio/`; o original fica aqui até ao fim do ciclo, porque é
aqui que se corrige se a revisão levantar alguma coisa. No fecho do ciclo, toda
a pasta vai para `9_arquivo/`.
