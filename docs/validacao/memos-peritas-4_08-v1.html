25_PR_218_BTE_32_MontepioGeral_SNQTB (Pos. 286)

Esta é talvez uma das partes mais importantes nestes subtipos de documentos. É a partir daqui que existem o maior número de falsos positivos, pois o que se está presentemente a analisar, são as novidades no texto. Assim, tudo o que não for novo, não deve ser considerado neste quadro. O texto consolidado precisa de ser sinalizado e excluído de uma primeira análise. Só quando é realizada uma comparação com textos anteriores, e existe uma novidade apresentada na formulação do texto consolidado, é que se pode apresentar essa questão aqui. Em 2025, como não foram feitas comparações diretamente em MAXQDA, decidiu-se apenas sinalizar as partes incluídas no texto consolidado enquanto tal, para que qualquer cláusula sinalizada nesse espaço, só fosse considerada e se mantivesse enquanto segmento codificado, se da comparação com as versões anteriores dessa convenção, se considerasse que existia uma novidade relevante para a análise de determinado tema. É importante manter o texto recolhido, pois é uma fonte de verdade e permite uma análise posterior, mas também é importante existir esta sinalização. Considera a melhor forma de o realizar.
